# nyaa-stream 0.6.0

## What's new

- Anime pages retain their release results and provide an explicit Refresh action.
- Home heroes prefer Fanart.tv backgrounds. Media pages use season-matched logos, TMDB episode stills, and dimmed Fanart.tv backgrounds.
- Build missing episode thumbnails from seeded torrents with up to ten concurrent captures.
- Preview downloaded video frames while seeking.
- Paste a magnet or info hash to play it directly or attach it to an episode or pack; edit, move, and remove attached sources.
- Use context menus for anime, episodes, sources, text fields, and playback controls.
- Customize ASS subtitle appearance and use quieter update checks with an in-app update flow.
- Install with branded Windows setup screens and selectable location and shortcuts.

## Fixes

- Bound long first-season Nyaa queries to avoid rejected searches.
- Preserve the playback resume buffer during controlled updates and include the MSVC runtime required by the torrent bridge.
