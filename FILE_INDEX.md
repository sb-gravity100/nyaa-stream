| `crates/anilist-client/examples/offset_debug.rs`, `crates/anilist-client/examples/relations_debug.rs` | Scratch tools for checking `cumulative_prequel_episodes`/AniList's raw relations data against live shows without launching the full app | backend, dev-tool |

| `src/PlayerView.tsx` | Full-viewport player: HTML5 `<video>` driven by `hls.js` against torrent-engine's HLS playlist, solid-black bottom control bar shown only on direct hover (play/pause, seek with a download-progress highlight, mute, volume, fullscreen, time, source-picker dropdown over the episode's release list, subtitle-track picker over `<track>` elements toggled via the native `TextTrackList` API) plus PotPlayer/YouTube-style keybinds, stremio-style `Buffering`/`StatisticsMenu`; seeking is a plain `currentTime` set, hls.js fetches the covering segment | frontend |
| `src/Buffering.tsx` | Stremio-style buffering indicator: a pulsing mark that fills via `clip-path` using `loadingProgress.ts`'s weighted readiness score, ported from stremio-web's `Player/Buffering` | frontend |
| `src/StatisticsMenu.tsx` | Toggleable peers/speed/completed/info-hash card, ported from stremio-web's `Player/StatisticsMenu` | frontend |
